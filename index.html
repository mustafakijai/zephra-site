Features

A copilot that does real things — and tells you exactly what it did.

No vague “AI magic”. Every capability below ships in the current beta.

🎙️

“Hey Yumika” wake mode

Opt-in hands-free mode. Yumika listens on-device for its name, plays a cue, then takes your command — even while another app is in front. Off by default, every launch.

⚡

Talk, pause, done

Click the mic and speak. Yumika sends your command after a short pause — or switch on review mode to check every transcript first. English and a set of Hindi commands.

🎵

Apple Music, verified

Play, pause, skip, volume, shuffle and “What’s playing?”. Search your library tracks and playlists, then say “play the second one”. Yumika checks Music’s real state before saying it worked.

🚀

Launch your workspace

“Start my work setup” opens InDesign, Illustrator and Safari together. App launches are allowlisted and always confirmed — no surprises.

🧭

Work mode: plans you approve

Describe a task — “Create project for Client A”, “Draft an email about brochure review”, “Research office design” — and Yumika builds a step-by-step plan. Review every step and file, pick a folder, then Approve and run. Each run writes an execution report and never overwrites an existing file.

Project folders + checklistLocal notesEmail drafts (.txt)Research worksheetsExecution reports
📄

One-word InDesign PDF

“Export InDesign PDF” checks for overset text and missing links, lets you pick a preset, and exports the active document to a fresh file.

🧠

Bring your own local AI

Optionally connect your own Ollama model on this Mac for longer, combined requests. It can only propose the approved actions — never shell commands or scripts.

🛑

Emergency stop

One click stops new commands and shuts down wake listening. Errors, sleep and screen lock switch the microphone off automatically.

How it works

From voice to done in three steps.

01

Say it or type it

“Hey Yumika” → cue → “Create project for Client A.” Or just type into the command bar.

02

Review the plan

Yumika shows each step, the apps it will open and the exact files it will write. Change your mind? Cancel.

03

Approve and run

It runs on your Mac and reports every step’s outcome and file location. Nothing is sent anywhere.

Privacy by design

Your voice never leaves your Mac.

Yumika was built the other way round from cloud assistants: local first, explicit always.

Read the privacy FAQ →
  • On-device speech only. Apple’s on-device recogniser, with no hidden server fallback.
  • Wake audio is transient. Ambient speech is checked for the wake phrase and discarded — never saved, uploaded or executed.
  • No account, no telemetry. No sign-up, no analytics, no paid backend.
  • Memory that forgets. Conversation history lives in memory and disappears when you quit.
  • Local AI, on your terms. The optional planner talks only to a loopback Ollama server you run.
  • No open ports. Yumika exposes no inbound network control.

FAQ

Questions, answered honestly.

Which Macs does Yumika run on?

macOS 13 Ventura or later. On-device speech must be available for your language on your Mac. The optional Ollama planner needs macOS 14+.

Does Yumika send my voice or files to the cloud?

No. Speech is recognised on-device with no server fallback, there’s no account or telemetry, and the optional AI planner only talks to an Ollama server running on your own Mac (127.0.0.1). If you point Ollama at a cloud model yourself, that’s your server’s configuration.

Is it always listening?

Only if you switch on wake mode — it’s off every time you launch. While on, macOS shows its microphone indicator, and audio is processed transiently just to spot “Hey Yumika”. Lock, sleep, errors or Emergency stop turn it off.

Can it send emails or manage my calendar?

Not yet. Email “drafts” are local text files you can copy into your mail app, and Calendar is an app-launch target only. Inbox and calendar integrations are on the roadmap.

Does it work with Spotify or the full Apple Music catalog?

Today Yumika controls the Music app and searches the music in your library and playlists. Full catalog search, album queues and Spotify are planned.

Is Yumika a general chatbot?

No — it’s a focused command and work copilot. It understands a growing set of commands and work recipes, and with the optional local model it can plan longer combined tasks from that approved set.

Is it safe to let an assistant run things on my Mac?

Yumika can only use an allowlisted set of actions, shows you the full plan first, asks before launching apps, never overwrites existing files and can’t run shell commands or generated scripts.
